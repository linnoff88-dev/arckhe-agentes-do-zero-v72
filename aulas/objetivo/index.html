Aula 1 · 12 min

O que é um agente, e o objetivo do seu

Agente não é mágica: é um modelo de IA dentro de um programa que deixa ele usar ferramentas, em voltas, até terminar. é a peça de todo sistema de agentes. Antes de escrever uma linha, você prepara o computador e decide o que o seu agente faz, o que não faz e como vai saber que ficou pronto.

Começar a aula

Nesta aula você vai

  1. 1As quatro peças de todo agente
  2. 2Os 10 passos que este curso segue
  3. 3Escrever um objetivo que dá para conferir
  4. 4Rodar um modelo de IA grátis no seu computador

Objetivo: instalar o Ollama com o llama3.2 e escrever o objetivo.md com o que o agente faz, não faz e quando está pronto.

02 · Os 10 passos, em quatro blocos

Clique em cada bloco. Cada aula cobre um ou dois passos.

1. Decidir

1. Objetivo: o que faz, o que não faz e quando está pronto (esta aula).

2. Harness e 3. Modelo: primeiro o programa em volta, depois o modelo que cabe nele (aula 2). O harness vem antes porque ele limita quais modelos você pode usar.

2. Construir

4. Ferramentas: o que o agente consegue fazer, não só falar (aula 3).

5. Instruções e 6. Memória: quem ele é e o que lembra de você entre uma conversa e outra (aula 4).

3. Proteger

7. Limites: freio de rodadas, uma pasta só e o seu OK antes de mexer no que já existe (aula 5).

Sem limite, um agente com ferramenta é um programa que faz o que um texto mandar.

4. Provar

8. Testar e 9. Medir: tarefas fixas, nota, tempo e rodadas (aula 6).

10. Iterar: mudar uma coisa, medir de novo e só manter o que melhorou (aula 7).

03 · Prepare o computador (uma vez só)

Clique no seu sistema. No fim, o bloco do terminal confere tudo.

1. Windows

Os comandos do curso são do terminal do Linux. No Windows, abra o PowerShell como administrador, rode wsl --install, reinicie e abra o aplicativo Ubuntu: é nele que você digita tudo.

Instale o Ollama dentro do Ubuntu com este comando: curl -fsSL https://ollama.com/install.sh | sh (ele pede a sua senha do Ubuntu). O WSL é o Linux que roda dentro do Windows.

2. Mac

Abra o aplicativo Terminal. O Python 3 e o Git costumam vir com as ferramentas de linha de comando: se pedir, aceite instalar.

Baixe o Ollama para Mac em ollama.com e abra uma vez.

3. Linux

Abra o terminal. Se faltar, instale com sudo apt install python3 git (Ubuntu e parecidos).

Instale o Ollama com o comando da página de download.

4. Sem editor

Você não cria arquivo do zero: o primeiro comando baixa o kit do curso (com o Git, o programa que baixa e guarda versões de projetos) e, em cada aula, um cp copia o arquivo da aula para a sua pasta.

Se quiser colar à mão, use um editor de texto simples e salve com o nome exato (agente.py, não agente.py.txt).

04 · O objetivo e o modelo no seu computador

Rode no terminal (no Windows, no Ubuntu do WSL). Os arquivos de todas as aulas estão no kit que o primeiro comando baixa.

Arquivo · kit/objetivo.md
# Objetivo do meu agente
Faz: lê as minhas anotações da pasta trabalho/ e responde sobre elas; lembra o que eu pedir.
Não faz: nada fora da pasta trabalho/; não substitui arquivo sem o meu OK.
Pronto quando: acerta pelo menos 5 das 6 tarefas do medir.py na minha máquina.
Terminal · baixar o modelo e criar a pasta
python3 --version                    # precisa ser 3.10 ou mais novo
cd ~ && [ -d agentes-do-zero-v72 ] || git clone -q https://github.com/linnoff88-dev/agentes-do-zero-v72   # o kit (em outra pasta que a sua)
mkdir -p ~/agente-do-zero/trabalho   # a pasta do seu agente
ollama list | grep -q "^llama3.2" || ollama pull llama3.2     # baixa só se ainda não tiver (2 GB)
ollama run llama3.2 "Diga oi em cinco palavras." 2>/dev/null
Exemplo do repositório
Python 3.12.3
Olá, como você?

A primeira linha confere o Python; a última é o modelo respondendo. Pedimos cinco palavras e ele deu três: o modelo nem sempre obedece, e é por isso que a aula 6 mede. Repare também: o kit fica em ~/agentes-do-zero-v72, e o seu agente, em ~/agente-do-zero, pastas diferentes.

06 · Prática: o ponto de partida

Só passe para a aula 2 quando os dois estiverem prontos.

E1 · Computador pronto

20 min

Prepare o computador pelo seu sistema e rode o bloco do terminal. O download do llama3.2 tem 2 GB.

Pronto quando: python3 --version mostra 3.10 ou mais novo, a pasta agentes-do-zero-v72 existe e o modelo devolveu uma frase.

E2 · O seu objetivo

10 min

Copie o modelo para a sua pasta (cp ~/agentes-do-zero-v72/kit/objetivo.md ~/agente-do-zero/), abra com nano ~/agente-do-zero/objetivo.md e troque pelas suas palavras. No nano: setas para andar, Ctrl+O e Enter para salvar, Ctrl+X para sair. Vale para todo arquivo que o curso mandar editar. Pode ser o mesmo agente do exemplo.

Pronto quando: o arquivo tem as três linhas, Faz, Não faz e Pronto quando, e a última cita um número que dá para medir.
