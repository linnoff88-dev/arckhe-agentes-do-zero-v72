02 · O agente.py da aula 2

Rode dentro de agente-do-zero/. O primeiro comando copia o arquivo da aula do kit para a sua pasta.

Arquivo · kit/aula2/agente.py
#!/usr/bin/env python3
"""Agente do zero (aula 2): o harness mais simples, que leva o seu pedido ao modelo e devolve a resposta."""
import json, os, sys, urllib.request

MODELO = os.environ.get("MODELO", "llama3.2")
URL = os.environ.get("OLLAMA_URL", "http://localhost:11434") + "/api/chat"


def cerebro(mensagens):
    corpo = {"model": MODELO, "messages": mensagens, "stream": False, "think": False, "options": {"temperature": 0, "seed": 1}}
    pedido = urllib.request.Request(URL, json.dumps(corpo).encode(), {"Content-Type": "application/json"})
    with urllib.request.urlopen(pedido, timeout=600) as r:
        return json.loads(r.read())["message"]


if __name__ == "__main__":
    pedido = " ".join(sys.argv[1:])
    resposta = cerebro([{"role": "user", "content": pedido}])
    print(f"{resposta['content']}\n(modelo {MODELO})")

03 · O que cada parte do arquivo faz

Clique em cada parte.

1. Configuração

As duas primeiras variáveis leem o ambiente: se você não disser nada, vale llama3.2 no Ollama local.

Trocar de modelo ou de servidor é mudar a variável, nunca o código.

2. cerebro()

Monta o corpo do pedido em JSON, envia por HTTP com a biblioteca padrão (urllib) e devolve a mensagem do modelo.

"think": False desliga o modo "pensar em voz alta" de modelos como o qwen3, que deixava a resposta lenta.

3. Principal

Junta as palavras do terminal num pedido, chama o cerebro() uma vez e imprime.

Uma ida e uma volta: ainda não tem ferramenta nem loop. Isso entra na aula 3.
